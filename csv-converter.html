Отдельный инструмент для уже собранных результатов

Один CSV на каждого участника

Добавьте результаты. Для каждого участника получится свой файл со всеми данными: сначала тренировочные, затем основные пробы. Одна строка — одна проба.

Обработка происходит в браузере. Содержимое файлов никуда не отправляется. Исходные файлы и работающий эксперимент не изменяются.

1. Добавьте результаты

Выберите вместе trials_…csv и participant_…csv для нужных участников. Пары определяются по коду сессии. Данные разных участников останутся в разных CSV.

Можно выбрать несколько файлов сразу или перетащить их сюда.

    2. Скачайте файлы участников

    В архиве тоже один CSV на участника. Если Excel показывает всё в одном столбце, выберите разделитель «Точка с запятой» или откройте через «Данные → Из текста/CSV».

    Предпросмотр

    Как устроен файл

    Рядом с каждым готовым файлом указана группа участника. Подпись берётся из сохранённого экспериментального условия. Если оно отсутствует или не распознано, это будет отмечено явно.

    В каждой строке повторяются общие данные участника: согласие, условие, решение о заданиях, ответы на инструкции и финальный опрос. Далее идут данные одной пробы: видео, эмоция, тип выражения, ответ, правильность, время реакции и досмотр.

    Сначала идут тренировки, затем основные пробы. Столбец phase_label содержит «Тренировка» или «Основная проба»; исходный phase сохраняет значения practice / main.

    Все подробные события сохранены справа в дополнительных столбцах. Например, playback_events.1.event — первое событие воспроизведения, playback_events.2.event — второе. Вложенных списков внутри ячеек нет. Технический журнал привязан к своей пробе; события без соответствующей пробы сохраняются в столбцах session_technical_journal….

    Если не хватает одного исходного файла, конвертер покажет, какой добавить. Он не восстанавливает отсутствующие ответы, не пересчитывает правильность или время реакции и не исключает тестовые или незавершённые прохождения. Одинаковые копии записей учитываются один раз; противоречащие версии вызывают сообщение.

    Повторные прохождения с разными кодами сессии получают разные файлы. Во всех CSV одной загрузки одинаковый набор столбцов. Эту HTML-страницу можно сохранить на компьютер и использовать без интернета.

    Конвертер работает отдельно от эксперимента и Google Drive.
