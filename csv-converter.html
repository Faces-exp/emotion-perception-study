Отдельный инструмент для уже собранных результатов

Развернуть CSV в обычные таблицы

Загрузите файлы результатов эксперимента. Списки внутри ячеек будут разложены на отдельные строки и столбцы. Основной файл для анализа сохранит правило: одна строка -- одна основная видеопроба.

Обработка происходит только в этом окне браузера. Содержимое файлов никуда не отправляется. Исходные файлы и работающий эксперимент не изменяются.

1. Добавьте результаты

Лучше добавить вместе trials_…csv и participant_…csv. Можно выбрать сразу несколько участников: файлы объединятся по коду сессии.

Или перетащите их в эту область. Дополнительные файлы можно добавить позже.

    2. Скачайте готовые CSV

    Все файлы -- UTF-8 с заголовками. Если Excel показывает все в одном столбце, выберите разделитель «Точка с запятой» либо откройте файл через «Данные → Из текста/CSV» с нужным разделителем.

    Предпросмотр

    Какие файлы получатся и что в них находится
    1. analysis.csv -- основной файл для Excel и Jamovi: отдельные основные пробы, ответы, правильность, RT, условие и три финальные оценки. Данные участника добавляются из соответствующего participant_…csv.
    2. trials_full.csv -- те же основные пробы со всеми отдельными техническими столбцами; списков внутри ячеек уже нет.
    3. participants.csv -- одна строка на участника с общими показателями.
    4. practice.csv -- тренировочные пробы отдельно от основных.
    5. playback_events.csv и technical_journal.csv -- отдельные строки событий. Коды сессии, фаза и номер пробы связывают их с результатами.
    6. orders.csv, instructions.csv и дополнительные таблицы -- развернутые порядки стимулов, подтверждения инструкций и остальные вложенные данные.

    Если загружен только participant_…csv, ответы на 48 основных проб из него восстановить нельзя: нужен также trials_…csv. Конвертер покажет имеющиеся данные, не создавая вымышленных ответов.

    Конвертер не пересчитывает RT и правильность, не меняет экспериментальное условие и не исключает тестовые или незавершенные записи. Совершенно одинаковые копии одной записи объединяются; разные версии одной и той же пробы вызывают понятное сообщение вместо произвольного выбора.

    Столбцы _record_id и _parent_record_id служат для связи технических таблиц. columns.csv в архиве описывает назначение столбцов.
