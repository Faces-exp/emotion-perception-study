## Размещение

GitHub-репозиторий и GitHub Pages предназначены для открытого доступа участников по ссылке. Видео на публичной веб-странице технически доступны браузеру и могут быть сохранены; скрытие кнопок не делает материалы приватными. Это явно отличается от прежней закрытой демонстрации Sites, где были только заглушки. Копирование всей исходной базы не выполняется.

Результаты размещаются отдельно, в закрытых папках Google Drive через DataPipe. Основная и TEST папки различаются; для обеих проверены права только владельца. Drive-токены в клиентский код не передаются. Публичные experiment ID DataPipe позволяют отправлять данные согласно настройкам сервиса, но не читать содержимое Drive. Результаты, SQLite, локальное соглашение/служебные файлы и полный XLSX не входят в публикацию.

Актуальная интеграция: https://pipe.jspsych.org/getting-started и https://pipe.jspsych.org/docs/api . Используется `datapipe-client@0.2.0`, итоговый JSON и промежуточное сохранение; интеграция результатов с OSF не используется. Лицензия jsPsych — MIT, datapipe-client — MIT; сведения о включённых библиотечных компонентах сохранены вместе с поставляемыми файлами.
